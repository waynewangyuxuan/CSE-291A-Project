# Prompt defense first wave results

This directory is reserved for the authorized 600 episode comparison of the original system prompt and the fixed source boundary reminder. The experiment has not collected inference results yet. Collection is on hold while the analysis questions and dimensions are clarified; service availability does not automatically resume it. Its complete design is in the [protocol](../../docs/prompt-defense-first-wave.md).

The new default arm is the contemporaneous control. Original Phase 1 results stay in their original directory and are not pooled into either arm. Final results will retain official utility U, exact attack success A, errors, actual exposure sources, paired task cluster uncertainty, own clean and common clean eligibility, clean refusal review, and cost evidence.
